# 视觉设计与素材

## 从内容到镜头

用简短表格组织镜头，字段可按项目调整：

| 字段 | 用途 |
| --- | --- |
| id / 内容依据 | 给修改、字幕、配音和素材稳定的对应关系 |
| 信息或情绪 | 观看者需要理解或感受什么 |
| 画面目的 | 这个镜头如何帮助理解内容 |
| 素材与图层 | 区分固定构图与需要独立运动的元素 |
| 运动和转场 | 用可见动作解释变化或连接信息 |
| 时长与依据 | 录音、阅读、操作、动作完成或指定时长 |

选择合适的视觉表达，不把所有内容做成相同的背景加字幕：

- 科普：用对象、关系、过程和前后状态解释概念，复杂过程按理解所需逐步出现。
- 产品：用实际界面或获准的概念界面展示具体操作和结果，关键状态留出辨认时间。
- 数据：先确定要表达的比较或趋势，再选择图表；核对数值、单位、坐标与动画终点。
- 叙事：让景别、主体行为与内容转折对应，避免与内容无关的素材堆叠。

先选少量代表静帧确立字体、色彩、构图和镜头语言，再补齐镜头。文字、UI、图表优先保留可编辑性；AI 图片仅在任务需要场景或插画等素材时使用。

## 图片生成与精确编辑

使用当前环境可用的生成或编辑工具并遵循其要求。提示词表达镜头用途和可核对约束，可删去不适用字段：

```text
用途：对应镜头、内容要点与影片画幅。
场景与主体：应该出现什么，主体在做什么。
视觉基准：参考图、画风、色调、光线、主体尺度。
构图：主要位置、阅读留白、运动需要的通路。
固定项：编辑时保持的镜位、背景、布局与物件。
变更项：只添加、去除或替换哪些内容。
避免项：与内容矛盾的元素、额外文字、遮挡和形体错误。
透明度：独立图层需要时明确真实透明背景。
```

检查实际图片，不能把提示词当作完成证据。精确文字与数字若不可靠，改用后期排版。选中素材保存进工程，留存必要提示词、参考文件和来源，不让工程只依赖工具的临时生成目录。

## 连续空间中的状态转换

产品前后状态、时间变化或人物消隐需要空间连续时，保持主体锚点、镜位、坐标与尺度。图片状态可通过同构图素材配准；界面与图表可复用组件，改变数据或状态。逐个检查起点、中间态和终点，避免长时间叠影或跳动。

若叙事需要“旧状态 → 空场景 → 新状态”，先准备原场景、同构图空场景和新场景，固定背景与光线，再安排消隐、停顿与显现。是否需要空景以及各阶段时长由内容与节奏决定。

每个状态重新检查字幕、前景和主体。空场景的留白可能在新主体出现后变成遮挡位置。

## 运动与构图

- 文字：保证对比、安全边距和阅读时间；入场动作结束后留出稳定阅读区间。
- 图表与图形：运动表达数据或关系的变化，标签与对象保持同步，不用效果改变数值含义。
- 图层：共享关联图层的坐标和镜头变换。复制原图局部做运动时，避免底层与局部同时显露造成加深或重影。
- 局部效果：位移、高光、模糊等限定在适当的遮罩内，保留边界与静止对象。
- 相机与转场：控制幅度以保留主体与阅读；从内容关系选择切换、淡入淡出或连续运动。

先看静态构图，再看运动极值、转场中点与完成状态。增加复杂度前，确认已有运动在实际片段中可感知且有用途。

## 插画叙事的线索与节奏

对跨镜头反复出现的重要线索，建立轻量台账：出现位置、需要观众认出的特征、当场新增的信息、后续呼应，以及实际观看的结果。需要辨认的伏笔和刻意难以确认的异常分别安排；同一物件的可识别特征保持连续。原文引句与新增剧情分开标注，文字修改反馈先回到来源核对。

涉及不可靠叙述时，记录谁看见异常、其他人物是否也看见、镜头是否给出独立证实。把角色的解释和观众能观察到的现象分开；设计中的歧义需要通过视角控制维持，不能用无意的素材穿帮代替。

静态插画的停留应有明确作用，如阅读、等待、动作完成或心理压力。观众把停顿感到像卡顿时，检查该段是否仍提供新的注意目标；可通过反应近景、物件插入、声音变化或合适的微动组织节奏。保留既定镜头语言：固定构图的段落也可切换景别，不必统一加推拉。时长、透明度和运动幅度依据具体影片判断。

关键线索在目标画幅、接近实际观看尺寸和正常速度下检查，记录观众实际辨认了什么、何时发现、产生哪些解释。代码、时间线和抽帧可验证效果存在；观看记录用于判断它是否被感知。没有完成的观看与听音项目保留为未执行，技术检查通过不能自动填成观众理解通过。
