# EP18 科学定位与改稿依据

完整逐项审校与原始来源链接见 `../review/scientific-script-review.md`。原稿保存在 `../source/script.md`，实际制作改稿和语音文本分别保留。

本片是以冰山、暗海、金缮纹样与金线表达隐私边界和人的参与的科幻思想实验。数学不完备性不能直接证明人类心智不可计算；不可压缩、不可计算、难预测、不公开与自主权不能互相等同。

金线表示人主动提供一个具体意图，系统据此重新规划；它不是解答一般停机问题的oracle。上方循环也不是哥德尔定理导致智能必然停机的物理证明。

纹样和水深均为生成艺术与空间隐喻，不展示真实人格数据、脑活动、随机源、密码学协议、隐私系统或遥测测量。没有“无穷灵魂熵”“宇宙唯一随机源”或对所有算法的绝对防御承诺。访问被拒的扫描只是边界隐喻，不解释为空气入水时的全反射。

人有权参与决定披露、目标与委托范围，是作品的价值立场，不冒充数学定理。已有研究表明从行为数据可能推断部分未主动公开的属性，但不等于完美读心；因此本片保留“算法也许能猜中一些”的限定。
