# 科学边界
本片为社会寓言 / 科幻思想实验，绝非社会最优的数学预测。

- 帕累托有效：在可行集合内，不存在使至少一人变好且无人变差的重新配置。不保证公平或社会幸福，更不意味着禁止创新、失业为零、方差为零。片中“锁死”来自额外的虚构治理规则：拒绝所有有局部代价的自愿改变。Pareto Efficiency Lock为本片文学命名，不当成已确立学术定律。
- 过阻尼：标准稳定二阶系统ζ>1时无振荡回归平衡，过大阻尼可使慢模态更慢；并非停止响应，更不等于生命死亡。片中按住钟摆是主动控制的视觉隐喻，不能当作过阻尼系统的真实实验。
- σ²→0只指片中被定义为“偏离安排”的虚构波动，未定义也未实测现实社会动力学方差。零方差不能由帕累托有效推导。
- 水滴、心跳、城市、资源均为代码创作的示意，没有真实伤亡/临床或社会测量。
