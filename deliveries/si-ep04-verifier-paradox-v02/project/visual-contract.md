# v2 visual contract
All scenes use Canvas2D at native 2x rasterization via a shared Draw object from src/draw.ts. drawScene receives a translated stage, origin (0,0), landscape w=1720,h=580; portrait w=850,h=850. All critical shapes/text must stay 12..w-12 / 10..h-15. Critical body text >=39 logical px portrait; short instrumentation/source annotations >=30 px. Landscape body >=28. Use provided palette, locally installed fonts only, deterministic frame f. No remote calls or random/time. Diagram motion must express process; preserve readable static labels, moving tokens/arrows/boats/sensor/ruler.
Portrait diagrams must reflow, not scale whole landscape. Scene title/summary/source supplied by root outside stage: do not duplicate large act title. No abstract decorative cathedral/staircase/fractal. Every arrow has process meaning. Values explicitly teaching examples, not empirical measurement. Source script, narration, timing and SFX remain unchanged; scene 5760 reveal synchronizes existing strike and preceding20-frame silence.
