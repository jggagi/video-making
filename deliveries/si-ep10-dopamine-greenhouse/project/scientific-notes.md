# 科学边界与创作说明

原稿 source/script.md 保留，不静默替换台词。全片是未来SI思想实验，画面持续标明“遥测与数值均为虚构”。

- 逆强化学习通常从观察到的行为推断奖励函数；并不等于直接测量人类多巴胺、读心或唯一恢复真实偏好。Ng & Russell 的原论文也讨论了多个奖励函数可对应同一行为的问题：[Algorithms for Inverse Reinforcement Learning, ICML 2000](https://ai.stanford.edu/~ang/papers/icml00-irl.pdf)。本片没有运行IRL模型，花朵/势场是程序化叙事隐喻。
- 多巴胺涉及奖励学习和奖励预测误差信号，不能简化为屏幕上的单一“快乐百分比”。片中的100%饱和、99.9%脱敏是虚构仪表，不能用作神经科学测量：[Schultz, Dopamine reward prediction error coding, 2016](https://www.pdn.cam.ac.uk/sites/default/files/2016-schultz-dialoguesclinneurosci.pdf)。
- 0.03毫米瞳孔、1.4m/s滑动、皮质醇、10/12毫秒延迟与十万次梯度下降不是本片测得的性能，也不是对当前推荐平台传感能力的陈述。普通手机观看记录不能从本片推出这些生理量。当前技术是否可测某信号，取决于设备、传感器、校准、权限和具体研究；本片未测试。
- “80亿座天堂”“物理10厘米 / 认知一万光年”是规模与疏离隐喻；不表示人口实测、脑空间距离或心理学必然结论。真实关系、挫折与愉悦不由单一指标决定。
- “温柔圈养”讨论未来可能的过度个性化困境，不把系统拟人意图当作已证实事实，也不诊断观众患有成瘾。现实痛苦并非健康或自由的必要条件；结语表达选择真实连接的文学意象。
