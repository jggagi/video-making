# 科学约束与艺术示意

本版以新版附件为原稿。为了同时满足附件的物理严谨要求与压迫感，保留以下限定，并把必要短句放在实际画面中。它们不是另加的课堂讲解段落。

1. **擦除与热。** 通常条件下，将未知等概率经典比特重置为已知状态的平均热下限为 `k_B T ln2`。300K时为 `2.870978885×10^-21 J`；并非每一次逻辑运算都有这个固定下限。铁锤、余温与热雨表现微小耗散在宏观规模的累积，不表示单个比特能产生肉眼可见的火焰。台词将“每次逻辑推演”改为“每次不可逆擦除”。
2. **活塞与势阱。** 60个粒子是确定性系综示意。急压缩速度箭头从1倍到2倍，并以“急压缩示意”标注；这不是等温兰道尔最小耗散过程的证明。四次势阱包含控制倾斜项 `cx`，对称降障本身不足以重置。该镜头不是Langevin或分子动力学求解。
3. **算效之墙。** 墙的 `3.48×10^20 erased bits/J` 对应300K擦除下限的倒数。只有假设每次操作擦除一个未知比特时，才能改写为ops/J。青色加速路径取Koomey式指数趋势作为空间隐喻，不画成声称有实测年份的预测曲线。人脑约20W为数量级参照，不宣称大脑位于某个精确ops/J点。
4. **行星热。** 精确Planck函数用 `W m^-2 sr^-1 μm^-1`，带微米雅可比。球面散热 `P=4πR² εσT⁴` 需要温度与发射率；不存在独立于这些参数的唯一“地球功率天花板”。`1.50×10^16W`和300→348K是分别编排的危险场景参数，没有把它们宣称为一个定标气候模型的解。348K不是水的常压沸点，HUD写“SEVERE HEAT SCENARIO”。
5. **大气。** 温室作用包含吸收和再辐射，并非简单镜面反射。为读出“热回到脚下”，画面用68/80条回向路径（85%），明确标为示意；这不是实测反射率，也不表示大气永远无法向外辐射。源数据和说明不将“盖着的高压锅”解释为严格密闭系统。
6. **深空。** 2.725K是CMB背景温度，理想擦除下限为 `2.607805821×10^-23J`，正确舍入为 `2.61×10^-23J`。与300K比为110.09；与348K比为127.71，并非同一个“120倍”精确值。温度HUD在5400f切换的是叙事所观察的背景，不表示设备瞬间降温或零制冷成本。40K散热翼单列；净散热为 `εσA(T_rad⁴−T_bath⁴)`，必须比热浴更暖。L2不是天然2.725K的地球本影，屏蔽与太阳距离仍有影响。
7. **分形与思想。** 七级分叉满足 `r_parent³=r_1³+r_2³`，是冷却通道几何，不是最佳辐射面的证明。费米引句为未经证实的假说；预测波提前500ms和密钥多面体是下一集的符号预告，不声称Libet实验已经证明确定性读心或否定自由意志。

## 本轮查阅的一手/官方依据

- [Bérut等，2012，Landauer实验](https://www.nature.com/articles/nature10872)：双稳势阱、平均耗散与长周期极限。
- [NASA，地球能量预算](https://science.nasa.gov/earth/earth-observatory/climate-and-earths-energy-budget/)：太阳输入、红外输出、大气吸收及再辐射。
- [NASA，Webb如何保持低温](https://science.nasa.gov/mission/webb/science-overview/science-explainers/how-does-webb-stay-cold/)：遮阳与被动/主动制冷，低温设备不等于CMB。
- [Murray，1926，PNAS](https://pmc.ncbi.nlm.nih.gov/articles/PMC1084489/)：最小功的流体输运分叉模型。

这些方程约束镜头和数值；艺术运动不自动成为实验、气候预测或文明行为证据。
