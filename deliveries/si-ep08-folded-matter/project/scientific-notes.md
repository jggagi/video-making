# 科学边界与原文保留

本片为科幻思想实验；所有应力色带、破坏、金色骨骼和城市均为程序化视觉示意，不是本项目求解的有限元分析、流体分析或实验结果。原稿完整保存，配音保留其诗性表达，画面中的持续限定与片尾S10防止把数字当实测。发布文案另作科学边界说明，不照搬“纯代码FEA证明”。

- “人脑算不出”“直线是浪费”“对称是无能”：原稿的夸张立场。现实工程会权衡成本、制造、可靠性、载荷，直线/对称本身不等于差设计，优化也可施加对称约束。
- 34.2%、10^8 ITERATIONS / SEC、+4,200%、78.4%、轻十倍强百倍、10吨：叙事参数，不是本片模拟或普遍工程性能。最后金色无红区也不是消除了应力；颜色表达载荷路径的视觉比喻。
- 拓扑优化是在给定载荷、边界和目标下寻找材料分布。结构承重的有限元分析不应混同流体模拟。逆向设计和仿生是相关思想，不保证“自然总最优”。
- 对照破坏没有真实材料、边界条件、疲劳/屈曲或制造检验，不可用作承载或安全结论。
- EP09光纤展示有限速度传播；“零秒华尔街”为标题意象，不声称零延迟超光速。
