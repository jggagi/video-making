# 感受 SI 的叙事与分镜

## 何时使用

当用户的 brief 指向“感受 SI”、想让观众先获得直觉，或明确要求把抽象原理变成可感受的影像时，使用本参考。若用户要教程、数据讲解或严谨推导，保留其指定的解释深度，不套用本参考来删减内容。

## 创作方向

本方向来自明确的制作复盘：图示即使准确，若连续堆叠仍会显得枯燥、信息过载。目标是让观众感到 SI 带来的规模、速度、压力、意外或不安，而不要求他们先掌握完整原理。

先确定观众看完后应留下的一种感受、一幅记忆图像或一个核心直觉。再选择能让观众经历它的动作和后果；不要先决定放哪张图表，再想办法让它显得有趣。

每一幕先写明预期感受与核心直觉，再组织成一个易读主体、一个动作和一个可见后果。用声音、节奏、空间尺度、重复或停顿帮助观众感受到变化；这些是可选表达手段，不是每幕都要齐备的清单。

理论负责守住因果正确。先用可感知的画面建立问题或直觉，再在需要处补充解释。只呈现观众理解当前因果关系所需的证据；其余公式、推导和来源可放在说明、片尾或补充材料中。

图示仍可用于澄清难以直接演出的关系。每次只突出当前叙事需要的关系和少量定位标签；删掉不影响理解的标签后，主体动作与因果仍应清楚。必要限定必须留在观众能看到的位置，尤其是删略会误导因果、确定性或适用范围时。

保留用户要求的原文、数字和必要限定。示意性数值要明确标为示意，不能伪造遥测、测量结果或真实数据；可能发生的结果不能写成必然，也不能把系统意图写成有意识的选择。

优先考虑有意义的物理或空间隐喻，避免只为“高级感”增加抽象装饰。隐喻要帮助观众读出变化；若容易被误读，应及时用简短说明或对照镜头校正。

以下只是表达例子，可按剧本改造，不是固定视觉模板：

- 小船反复绕行、庆祝胜利，终点却始终遥远：让观众感到忙碌与进展之间的落差。
- 同一错误动作持续复制并填满画面，错误后果随之扩大：先让规模变得可见，再让重复累积出压迫或不安。
- 预测中的幽灵与真实弹簧/质量块先分离，再由测量结果校正：把预测与现实的差异变成可观察的事件。

镜头数、每幕画面数、标签数量和隐喻比例都是创作选择；这些倾向不构成“每幕只能一个标签”或任何固定风格规则。为讲清关键因果，可以加入解释镜头或更完整的图示。

## 可复用的镜头提示

为每段记录以下字段即可；它们是帮助思考的提示，不是强制机器格式，也不要求增加脚本或自动批准门槛。

| 字段 | 记录内容 |
| --- | --- |
| 段落 / 场次 | 发生在叙事的什么位置 |
| 预期感受与核心直觉 | 希望观众此刻感到或领会什么 |
| 主体与动作 | 画面中谁或什么做了什么 |
| 可见后果 | 观众能从画面读出的改变 |
| 声音、节奏或尺度 | 用哪些听觉、时序或空间线索加强体验 |
| 必要证据与限定 | 哪个事实必须可见，什么条件不能被误读 |

## 体验检查

完整渲染前，先完成一段具有代表性的短片段，并用真实旁白和声音检查它。评估整片的观看语言是否一致，不能只在结尾几张卡片上补情绪。

先以目标尺寸、正常速度连续观看一次，记录留下的图像、感受与核心直觉：删去非必要标签后，动作和关键因果是否仍然清楚？若需要暂停才能读懂，先简化呈现或重排信息，再继续完整制作。有真实观众反馈时，记录其实际感受与复述；没有时保留待确认，并继续已授权的制作，不新增默认审批或等待环节。

体验检查补充叙事与观感判断；它不能替代原有的内容准确性、媒体、声音和交付检查。自动检查、模型辅助检查、创作者自评与真实观众或设备验收分别记录，不能互相冒充。
