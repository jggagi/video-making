# 《兰亭集序》案例

这是方法来源的具体实例，参数是当时的制作选择。

## 文本到画面

| 文本 | 视觉选择 | 用意 |
| --- | --- | --- |
| 群贤毕至，少长咸集 | 不同年龄文士沿曲水列坐 | 表现聚会与人物关系 |
| 茂林修竹、清流激湍 | 竹林、局部水面运动 | 让景物描写成为可见的动作 |
| 流觞曲水、一觞一咏 | 耳杯循水道移动、纸面逐笔书写 | 连接器物、活动和文章 |
| 仰观、俯察 | 开阔天空、溪边草木近景 | 用景别转变对应观看方向 |
| 已为陈迹 | 同构图人物消隐，留下空溪 | 文学性的记忆与人事变迁 |
| 一死生为虚诞，齐彭殇为妄作 | 保留完整否定句 | 不把思考简化成无差别的乐观或虚无 |
| 后之视今，亦犹今之视昔 | 古人雅集 → 无人曲水 → 现代衣着游客 | 让时间关系成为点睛动作 |
| 后之览者，亦将有感于斯文 | 回到现代游客 | 呼应博物馆里正在观看的观众 |

## 古今转换的实施

先准备古人雅集与无人曲水两个配准场景，再以无人场景为底图生成现代游客。现代夹克、长裤、运动鞋、背包让时代差异清晰；竹林、树木、岩石、水道、镜位和画风保持一致。人物不进入水中，不另加建筑或标识。

这个镜头长 175 帧、24 fps：镜头内 30–64 帧古人消隐，64–78 帧空景停留，78–114 帧游客显现。三个状态使用同一镜头缓移和水面遮罩。该时序服务于已有男声句段，不作为其他影片的固定模板。

实际抽帧发现引句覆盖中央游客面部、前景竹叶遮住远处游客，因此上移引句并移除该镜头不合适的前景层。这个修正来自实际画面，而不是仅检查代码。

## 本次交付选择

全文 17 个正文镜头，26 段合成男声，约 3 分 9 秒。百炼中国站使用 `cosyvoice-v3-flash` / `longsanshu_v3`，这是当时已验证的提供商与音色选择；新任务应重新判断适配和可用性。

4K 母版为 3840×2160、4535 帧，1080p 由母版缩小，音轨保持一致。背景画作原始尺寸约 1672×941，4K 输出没有被称作原生 4K 画作。现代字形逐笔书写也没有被称作王羲之真迹。

校验覆盖全文、时间轴、代码、局部预览、两种分辨率的完整解码、最终视频抽帧与章节跳转；博物馆现场屏幕和音响试播仍是单独的验收环节。历次成片和修改前源码保留，可继续迭代。
