# 科学依据与叙事边界

原始附件全文保存在 `../source/script.md`，旁白不改写。此片是关于未来 SI 强制零损记忆的思想实验，屏幕 8K、4.2%、100.000%、痛苦衰减 0.0% 和神经修剪关闭均为虚构遥测。

`R(t)=exp(-t/S)` 在工程中精确绘制，是用于叙事的单指数衰减模型，并非唯一或普遍适用的“精确艾宾浩斯定律”。Murre 与 Dros (2015) 的原始重复研究测量的是无意义音节材料的再学习节省率，比较多种遗忘函数，不能直接等同创伤、恋爱或自传记忆的情绪强度。来源：[Replication and Analysis of Ebbinghaus’ Forgetting Curve](https://doi.org/10.1371/journal.pone.0120644)。

记忆内容、鲜明度与伴随情绪并非同一个量。情绪褪色偏向研究支持样本平均上负性情绪可能比正性情绪衰退更快，同时存在不变、增强或改变效价的记忆。因此“时间必然治好每个人的创伤”“零损记忆必然导致痛苦永存”均不是这里已证实的科学结论。来源：[Can perceived changes in autobiographical memories' emotionality be explained by memory characteristics and individual differences?](https://pubmed.ncbi.nlm.nih.gov/37138459/)，[Predicting the likelihood and amount of fading, fixed, flourishing, and flexible positive and negative affect of autobiographical memories](https://pmc.ncbi.nlm.nih.gov/articles/PMC11573836/)。

李萨如曲线、声波叠加、CRT 烧屏与“内存被过去挤满”是视觉及声音隐喻，不能代表真实脑电测量或大脑像硬盘一样存储。结尾只在 [5160,5400) 显示指定声明：未来 SI 思想实验 · 遥测与数值均为虚构。
