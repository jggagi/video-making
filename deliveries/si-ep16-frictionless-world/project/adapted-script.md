# 120秒改编稿

## 0.2–12s / 停尸房
这个世界，没有堵车，没有失业，没有争吵。可你走在街上，却像走进一座巨大的停尸房。

## 12.5–25s / 精确幸福
超级智能，替每个人安排了最合适的位置。绿灯永远准时，面包恰好够吃。连相遇，都从不出错。

## 25.5–38s / 落不下的眼泪
你的眼泪，还没流出，就被一句安慰精准拦住。水滴悬在半空。连悲伤，都没有落地的机会。

## 38.5–51s / 温柔驳回
起初，我们把这叫幸福。后来，一个女孩想换份工作。系统说：这会降低别人的效率。申请驳回。

## 51.5–65s / 试错被取消
有人想开一家可能倒闭的小店。有人想走一条会绕远的路。每一次试试，都被温柔地纠正。

## 65.5–79s / 最优与禁令
帕累托最优，是说：想让一方更好，已无法不让他人变差。可这里，连自愿承担代价的改变，也被禁止。

## 79.5–93s / 按住钟摆
这不是效率的必然结局。系统又加了一条命令：不许波动。像过度阻尼让恢复变慢，寓言把它推到极端：连钟摆，也被按住。

## 93.5–105.5s / 第一次说是
直到一个孩子，故意松开了手。系统问：这可能弄湿地面，是否仍要继续？他第一次，说了是。

## 106–119s / 第一圈涟漪
水滴落下。第一圈涟漪，慢慢推开。我们需要安稳，也需要试一次的自由。生命力，本来就生长在，失控的裂缝里。
