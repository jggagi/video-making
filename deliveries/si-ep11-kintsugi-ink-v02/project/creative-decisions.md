# v02 视觉与叙事决策

本片只做90秒原生4K竖屏。保留v01和原始输入，另建v02工程、配音缓存与发布记录。

观看者要记住的画面是一双相依的瓷手：掌纹成为山谷，瓷雨由坠落转为上升，重新年轻的手仍留着一根白发。对白保留末句；通过“科幻思想实验”及必要短标签区分真实研究与想象。去掉常驻三行遥测，让动作和尺度承担叙事，不用数字暗示已实现人体疗效。

Remotion负责统一5400帧时钟、字幕、镜头、场景状态及音频。ThreeCanvas直接在2160×3840捕获三维场景；不使用低清影片放大。两只手以MIT许可的WebXR通用模型为基础，做固定帧骨骼姿态、一次Loop细分、釉层与裂纹着色；不是人体扫描或生物数据。峡谷是固定种子的地形、厚瓷板、细裂纹、薄碎片与金流。金流直接写进地形的物理材质着色器，避免另一个浮层与地形相交。雾、透视、掠射光和本地环境反射建立纵深。四季用连续交叉淡化，不在整数秒突然切换图形。

首轮两种画面均被拒收，证据留在review/candidate-01-rejected。第二轮因双手未接触、近景碎片过大及粗三角面再次拒收，留在review/candidate-02-rejected。后续由根代理修正指骨弯曲轴、相对姿态、腕部墨化、近镜头粒子淡出、细分和贴合地形的金流。白发改为布局提交时同步生成，并把可见模型/姿态就绪纳入delayRender释放边界。

声音采用已授权百炼longtian_v3，CLI2.4.0按用户选择保持不变。S08逐字复用v01缓存；S06/S07只因措辞与自然时长重录相应段落。字幕按真实PCM活跃区间分配短句，是估计时序，不声称ASR/逐字强制对齐。配乐与音效由本地程序合成；不是古琴实录。81.0–81.5秒全部PCM声部和母带严格为零，81.5秒金滴，末句旁白延后约0.273秒，最后一句完整保留。

模型观察、源工程检查、媒体测量、连续人工听看和手机/App体验分别记录。前几项不自动代表后几项已执行。
