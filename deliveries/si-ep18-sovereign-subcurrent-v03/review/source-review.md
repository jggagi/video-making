# 源工程代表帧观察

观察材料为 source-contact-v01.jpg（初始轮廓方案）及 source-contact-v02.jpg（修订），由本版原生 4K 源帧缩至360px。

初轮问题：暗部轮廓过细、潜流只像平行波、终幕心印尚不易读作虹膜。已增加轮廓层级、局部暖墨底、八条绕流轨迹/移动粒子、黑色瞳孔与32根径向金色虹膜细丝。确认节点增加可读按钮。新版能读出暖色原形、下方冷色副本逐渐变金、影子越位，以及终幕金色虹膜。无透视或三维扭曲，HUD完整字段/值分时置于三行之内，360px未观察到边缘裁切。

这是模型对源帧的观察，不是最终编码视频的连续听看通过。当前截图未包含按真实PCM安排的最终字幕；最终文件仍需重新抽帧与全帧筛查。真实观众体验与目标设备播放未执行。
