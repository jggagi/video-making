# EP04 v3：让结尾只做一件事

120秒、60fps，原生横屏3840×2160及竖屏2160×3840。前105秒沿用v2；最后15秒按用户反馈减少信息。原剧本、十段中文旁白、19段字幕、声音母带和事件时刻全部保留。没有新增云端生成调用，v1/v2均保留。

倒数第二幕：继续使用上一幕弹簧。琥珀实物在下，青色预测虚影在上；虚影移到实测位置，让观众直接看到校准。只保留预测、实测两个标签。去掉四步流程、反馈回路、解释小字和重复大引句；原引句只在旁白与字幕中出现一次。校准后的共同运动表示模型跟随新观测，不表示一次校准保证未来正确。
