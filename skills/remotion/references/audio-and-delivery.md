# 声音、时间轴与交付

## 配音路径

先检查已有录音、音频缓存和用户选择。有可用旁白时不为视觉修改重做配音。明确静音、只要音乐或没有旁白的任务无需启用 TTS。

云端 TTS 按当前可用的提供商工具与执行要求使用。保持用户的提供商、音色、输入范围和预算。已授权的同项目调用可以继续；不能把另一项目或本案例的授权作为依据。不在聊天中索要密钥，不在清单中保存密钥、令牌或带签名的下载链接。

选型时核对官方的当前价格、可用地区、预置音色、SSML/音素支持和格式限制。“高性价比”应比较实际需要的能力与费用；便宜但只有克隆音色的模型可能不适合需要现成男声的任务。先生成短样本，确认真实返回模型/音色和可解码的音频；人工试听与结构检查分别记录。

字幕文本和发音控制独立保存；人名、术语和多音字需要时校准。分段保留语义和自然停顿，不追求平均句长。古文的专门处理见 [文学短片](literary-film.md)。

内容缓存可按“文本/SSML + 模型 + 音色 + 语速 + 输出格式”计算键，复用时核对文件散列与解码时长。提供商失败时保留已有结果并诊断具体错误，不静默切换模型、音色或无限重试。

## 时间轴

保存脚本或内容 id、音频路径（如有）、实际时长、起始帧和持续帧。字段可适配项目，保留可核对关系即可。无旁白时，按阅读与动作完成所需时间安排；静音仍应能够理解关键内容。

- 从真实音频采样数或媒体探测结果取时长；`ceil(seconds × fps)` 可覆盖一段完整旁白，再加需要的停顿。
- 检查镜头与字幕是否连续、越界、重叠不当，以及关键内容是否完整出现。
- 为转场和动作完成留出时间；字幕不应在语音尚未完成时提前消失。
- 用户限定总时长时，先判断内容能否清楚表达。根据授权调整脚本、语速与镜头；无法兼容的要求需要用户决定，不通过漏读或截断掩盖冲突。
- 只有视觉变更时，保留时间轴与音轨，使用散列或适当的差异检查确认；这样字幕和既有配音无需重新同步。

把旁白与音乐、环境声分别管理。旁白期间降低背景声，检查峰值和实际听感。不要把某一影片的 LUFS 数值当成所有展厅的标准，也不要只凭“未削波”宣称听感合格。合成声音如实标明，真人录音与音色克隆分别说明来源。

## 导出与证据

沿用现有工程依赖与 Remotion 版本，使用其渲染入口。新的工程才选择必要的版本与依赖。重型任务遵守当前工作站的资源规则；这些规则属于运行环境，不写死个人路径到通用 skill。

先渲染受改动影响的关键静帧与短片段，确认内容、布局、运动极值和前后转场，再渲染全片。按播放设备要求选择规格；H.264 / AAC、MP4 fast start 是常见交付选择，透明视频等其他输出另按目标播放器能力确定。

| 证据 | 能说明什么 |
| --- | --- |
| 内容/时间轴核对 | 脚本、数据、操作状态、字幕和帧区间符合要求 |
| 代码检查 | 工程代码通过相应检查，不代表画面已经正确 |
| 素材与渲染静帧 | 构图、文字、数字、遮挡与状态符合设计 |
| 实际短片播放 | 转场与运动能播放；听感只在实际审听后确认 |
| 最终文件探测、完整解码、散列 | 规格、帧数、完整性和交付文件身份 |
| 最终视频抽帧、本次交付的播放器跳转 | 交付视频与涉及的预览操作实际可用 |
| 现场试播 | 大屏距离、亮度、音响、循环与观众体验 |

展示时区分输出分辨率与素材原生分辨率。由同一母版缩小预览版可保持时序；音轨不需要修改时尽量保留同一音轨。导出文件另存版本，避免覆盖已认可成片。

## 博物馆与展厅模式

仅在播放场景确为展厅时使用这些判断：

- 根据屏幕画幅、观看距离、环境亮度安排字体、安全边距与文字停留时间。
- 明确是否外放、定向音响或静音。静音时画面与字幕仍能传递必要信息。
- 为循环衔接检查首尾画面与音量变化，按展厅需要提供循环与全屏入口。
- 自动完整解码、桌面播放与现场试播分别记录。交付可试播版本，不把桌面测试标成现场验收完成。

交付可编辑工程、成片、独立字幕（如使用）、必要音频、素材/提示词清单与简洁校验说明。只打包当前任务所需内容，不把账户凭据或工具安装缓存当成作品资源。
