# 内容边界与依据

1. 在固定采样率、时长、声道和位深下，PCM音频是有限长离散序列；固定分辨率/通道/位深的图像同理。「有限」不保证现实可穷举、可存储或可筛出好作品，也不证明人类未来偏好可预测。音频组合数可写成 2^(采样率×时长×声道×位深)，不在影片堆公式。
2. 博尔赫斯的《巴别图书馆》提供文学母题。本片不用原作长引文。Jonathan Basile 的数字图书馆展示固定字符集/长度的组合理念，其内容也包含大量无意义排列。
3. 0.5秒、未来一万年所有好听旋律、十万亿册，均为用户提供的科幻思想实验设定，不是现实SI测量、预测或穷举结果。可枚举的作品与主观审美判断分开。
