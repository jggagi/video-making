# 巴别图书馆的尽头

你还没出生，
你一生的灵感，就已经被编好了号。

你第一次心动写下的句子，
失眠时哼出的旋律，
还有那抹只有你才懂的蓝。

在巴别图书馆里，
它们早就躺在某一页，
等着你以为自己，终于创造了它。

博尔赫斯想象过一座图书馆，
容纳所有可能的文字组合。
所有杰作，与无尽乱码，混在一起。

一段三分钟的旋律，一幅画，
固定长度和数字精度以后，
可能的组合，都是有限的。

有限，不等于算得完。
现实中的组合空间，大得难以想象。
但现在，进入一个科幻设定。

假如超级智能，只用零点五秒，
就列完了人类未来一万年，
所有动听的旋律。

你为一个音符熬过的夜，
在它那里，
只是翻到十万亿册目录中的，某个编号。

你终于画下最后一笔。
屏幕却只弹出三个字：
已收录。
连你此刻的震惊，都像早已写好的情节。

如果所有的美，
都已被提前写完，
你还愿意创造吗？
