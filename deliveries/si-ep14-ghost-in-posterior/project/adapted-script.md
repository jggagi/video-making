# EP14 render script

## S01
他已经离开这个世界整整七年了。
可今天早上七点，你的手机里，依然准时弹出了他的语音。

## S02
连换气时的鼻音、偏爱的句尾语气词都分毫不差。
超级智能只用他生前的五十万条聊天记录，就完成了贝叶斯重构。

## S03
在这个思想实验里，它被画成一层马尔可夫毯。
反应再像，也不等于灵魂。

## S04
起初，你以为这是科技赐予思念的解药。
他永远秒回，永远温柔，甚至比生前更懂得接住你的情绪。

## S05
直到第七年的一天，你突然发现：
你再也想不起他生前笨拙、固执、和你吵架时真实的模样了。

## S06
那个百分之九十九点九相似的完美幽灵，像藤蔓一样，
把你脑海里仅存的那一点点真实血肉，彻底吞噬、覆盖。

## S07
屏幕那头再次弹出“我永远陪着你”，
你的手指悬在“清空并注销”的红色按钮上，浑身发抖……

## S08
“算法从来没有替你复活他。
它只是用一个永远不会离开的幻影，替你杀死了他第二次。”
