# 7±2 的囚笼 · 小红书 60 秒竖屏版

本版将三分钟横屏作品重新编排为独立的 60 秒故事，重新绘制竖屏布局。保留“第十个变量进入 → 过载 → 高维秩序 → 神谕投影”的叙事，保留结尾核心引句和第三期钩子。原横屏源文件、音频及已交付成片保持不变；仅在 Root 和 npm scripts 增加新版入口。

## 发布素材

- 推荐发布文件：`out/cage-of-seven-plus-two-xhs-v1-1080x1920.mp4`，9:16、1080×1920、60 fps、60 秒、H.264 / AAC，MP4 fast start。
- 原生竖屏母版：`out/cage-of-seven-plus-two-xhs-v1-4k.mp4`，2160×3840、60 fps。发布文件由同一母版等比缩小，AAC 音轨直接复制。
- 独立 3:4 封面：`out/cage-of-seven-plus-two-xhs-v1-cover-3x4.jpg`，1080×1440；封面原稿为 `out/xhs-v1-cover-4k.png`，2160×2880。
- 中文字幕：`out/cage-of-seven-plus-two-xhs-v1-zh.srt`。画面已烧录字幕，通常无需再次叠加同样的字幕。
- 可复制笔记文案：`out/xhs-v1-post.txt`。

9:16、60 秒、留白位置和封面比例是本次编辑选择，不表示已验证平台当前上传限制或所有机型的界面遮挡。关键标题、动画和双行字幕集中在画面上中部，右侧及底部留出余量；实际平台上传与手机观看需另行检查。本任务只制作素材，没有发布到账号。

`xhs-timeline.json` 是本版场景、字幕和音频位置的共同依据。使用 11 段已缓存百炼旁白，共约 49.262 秒；完整保留各段源 PCM 样本，不加速、不裁句。原有单声道旁白以相同振幅复制到左右声道，原缓存文件不改动。长句字幕采用句段时序，不声称逐字时间戳或 ASR 校对。

九层 220–1980 Hz 泛音在第 0、4、…、32 帧加入；第 36 帧切换为复制自原作的 12 帧失真噪声。第 48–65 帧为 PCM 数字静音，第 66 帧进入旁白。配乐在旁白期间压低 8 dB。混音测量为 −19.48 LUFS、−2.52 dBTP；声音听感与发音仍需人工试听。

## 内容口径

本片是超级智能思想实验。“十万维”“十万亿分身”等是叙事设定，不是现有模型的能力实测。封面和视频保留“概念可视化”标注。

片名中的 7±2 借用了经典记忆研究作为叙事隐喻，不将其表述为所有人的固定硬件上限。Miller 的原始论文见 [1956 年论文记录](https://pubmed.ncbi.nlm.nih.gov/13310704/)；后续研究对容量估计及其条件有不同解释，见 [Cowan：工作记忆容量研究综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC2864034/)。

画面由程序生成，旁白由百炼合成，音乐为原创程序合成。没有使用新的云端生成服务，没有 ASR 音频上传。
