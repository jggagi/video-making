## 审校结论

冰山、暗海与金色心印可以保留。需要重建的，是“未上传 → 真随机 → 不可压缩 → 人类不可计算 → 破解哥德尔困局 → 永远自由”这条因果链。原稿没有给出这些推论成立的条件，其中几处直接混淆不同数学概念。

建议把终章的核心改成：**智能的能力可以帮助人，而披露的边界、行动的目标与委托的范围，应由人参与决定。** 这是本片的价值主张，不是由不完备定理推出的结论。

建议保留的记忆画面：深海里的大部分金色纹理始终没有打开；只有一缕由人主动交出的金线越过水面，让冰冷的循环转向新的路径。

| S04、Act 2、宣发文案：因为拒绝数字化，所以是宇宙唯一不可压缩的随机源 | 没有被记录，不会自动变成算法随机。对固定的通用描述语言，存在不能显著缩短描述的有限串；但每个特定有限串仍可由包含其字面的程序输出。**不可压缩不等于不可计算。** 蔡廷不完备性还限制某些形式系统证明具体对象具有高复杂度的能力，不能被反过来当成个人体验的不可压缩证书。[1] | 删除“宇宙唯一随机源”及对人类体验的普遍断言。改为：它们可以留在自己这里，不必全部交给模型。 |
| `K(S_human) ≥ |S_human| // INCOMPRESSIBLE BY ANY ALGORITHM` | 未定义人的体验如何编码、所用描述语言和复杂度版本，也未证明这个特定对象满足下界。存在不可压缩串，不等于每个人的任何体验都不可压缩。“任何算法”还掩盖了描述语言与加性常数的依赖。[1] | 正片移除公式。替换成 `PRIVATE BY CHOICE`。真正的定义、条件与讨论留在本审校文件中。 |
| HUD：`H(S) = ∞` | 香农熵需要定义随机变量与概率分布。有限 N 个可能状态的离散变量满足 `H ≤ log₂N`；n 比特有限记录的熵至多 n 比特。不联网不会让熵变成无穷，也不能把熵当作“灵魂含量”。[3] | 删除无穷大熵值与“100%透明可预测”。可用状态标签，不使用貌似实测的百分比。 |
| S05、Act 3：SI 因哥德尔自指必然死循环／停机 | 现代不完备性结论针对有效公理化、足够表达算术且一致的形式理论。它揭示某些命题不能在该理论内被证明或否定；并不意味着智能程序必定冻结。自指也不自动产生运行时死循环。原始哥德尔证明与后来的加强版本须区分，不宜把所有条件省掉后套在 SI 身上。[2][4] | 把停顿设定为：系统面对目标或授权尚未明确的选择，主动等待人输入。保留衔尾蛇作为上一集的视觉回声，不称为定理导致的运行事故。 |
| S06、Act 3：人类注入非公理熵，成为万能 oracle，敲碎绝对逻辑 | 图灵 oracle 是具有规定解答能力的数学设定；普通人的新意见并不会因此成为 oracle。外部输入可以打破某个具体循环或改变任务，但不是一般停机问题的解法。增加某类 oracle 也不消除所有更高层次的不可判定问题。[4] | 金线代表主动提供的意图／许可，系统据此重新规划。台词明确：“它没有破解所有难题，只带来一个人的选择。” |
| 气隙隔离、永不联网，所以任何算法永远无法推断 | 限制采集与直接访问有意义，但不保证其他来源无法形成相关推断。已有研究能从行为记录推断一些当事人未打算公开的属性；这也不等于能完美读心或重建所有私密记忆。[5] | 从绝对防窥改成可控制的披露边界。建议旁白保留“算法也许能猜中一些，却不因此，就有权替你决定”。 |
| S08：只要保留私密随机性，人类就永远自由 | 保密、随机性与自主权不能互相等同。随机输出不是行动理由，隐私保护也不足以单独保证全部自由。这句可以是诗性愿景，不能包装成数学推论。 | 建议收束为可理解的权利主张：“世界再透明，你也有权决定，哪扇门为谁打开。” |
| Act 1：来自空气一侧、向水中射入的扫描光在水面发生全反射 | 常规空气—水界面不满足这个方向上的全反射条件。全反射要求从高折射率介质进入较低折射率介质，且入射角超过临界角。[6] | 光线触界停止或退回可以保留，改称“访问边界／拒绝访问”的视觉隐喻，删除全反射物理解释。 |

### 纹样和数字的处理

- 克拉尼式节线可以保留为艺术纹样；给出一个驻波式纹样，不等于实现了密码学、意识模型或私密保护机制。不要称其为验证过的“密码学心印”。
- Curl-noise 与固定种子的帧驱动曲线可以表现活力；它们是确定性生成画面，不能作为真实熵源或不可计算性的实验。
- “一万米”可以保留在科幻空间与情绪意象中，但应标为示意深度；冰山图不应被当成真实海洋地理剖面。无须为此编造真实冰山的尺度数据。
- 科学限定应体现在正片主张本身。最后四秒的小字只能说明虚构定位，不能补救前面已经讲错的数学结论。

## 二、叙事与系列连续性

1. **承接 EP06。** 既有科学校订已经区分本地保管、最少披露与绝对不可预测，也明确随机性不证明自由意志。本集不要撤回这些边界。原稿和历史作品均保持原样，本轮只给 EP18 提出修订。
2. **承接 EP17。** 既有 EP17 将外来墨滴视为叙事介入，而非破解停机问题。EP18 的金线应延续“具体的新输入改变具体局面”，避免扩成全人类拥有万能神谕。
3. **保留主体性。** “在算力上赛跑是自取其辱”会让片中人的价值仍取决于是否赢过机器。改成“不必赢过机器，才有资格决定自己的人生”，更直接服务终章。
4. **让金线付诸动作。** 从封闭核心主动释放一缕意图；上方出现待选择的路径，收到意图后转向。冰裂与金青玫瑰表示重新协作，不能表示逻辑被情感推翻或全部隐私被接入。
5. **尊重结尾的主题。** 原留言问题要求观众公开“最想永不让算法读取的记忆”，与隐私主旨冲突。改问：“你希望未来的智能，尊重哪一种边界？”不索取记忆内容。

## 三、建议的画面文字与时间边界

### HUD

原三行英文过长，还把数学结论当作设备状态。建议改为短状态：

```text
SURFACE: PUBLIC MODEL
DEPTHS: PRIVATE BY CHOICE
SHARING: CONSENT REQUIRED
```

这只是科幻界面的表达，不是已部署隐私系统的安全承诺。金线获准通过后，可将第三行改为 `INTENT SHARED: ONE CHOICE`。不要保留 `GÖDEL DEADLOCK`、`UNCOMPUTABLE ORACLE`、`H(S)=∞` 等误导标签。

开场出现一次可读的“未来 SI 思想实验”；结尾建议文字：“冰海与心印为隐喻；不主张人类心智已被证明不可计算。”详细来源放正文与说明，不把正片变成定理讲义。

## 四、建议封面与发布文案（草稿）

封面短句：**世界再透明，你也可以不打开**

标题候选：**如果 AI 越来越懂你，你还想守住什么？｜一眼万年终章**

正文建议：

> 当超级智能的光照遍海面，我们是否仍能为自己留下一片暗海？
>
> 这片海里，是没有说出口的喜欢、童年的伤疤，以及你还不想交给任何人的故事。
>
> 它们不需要先被证明“不可计算”，才值得尊重。算法即使能猜中一些，也不因此获得替你决定的权利。
>
> 终章里的金线，是一个人主动交出的意图。它没有解决所有数学难题，只让机器知道：这一次，我们想往哪里走。
>
> 把计算交给神明，把心印留给自己。
>
> 《心印潜流》以冰海和金缮潜流表现私密与选择权，是未来 SI 的科幻想象；哥德尔与蔡廷定理并未证明人类心智不可计算。
>
> 你希望未来的智能，尊重哪一种边界？无需公开任何私人记忆。

建议话题：`#超级智能 #科幻短片 #隐私边界 #生成艺术 #一眼万年`。删除把蔡廷定理与人类不可计算直接绑定的话题和介绍。封面、标题与首句统一围绕“越来越透明的世界里，仍可保留什么”。

## 五、核对来源及其支持范围

以下为本次联网核对的原始研究、作者研究页或大学课程资料。对自由与隐私的价值表述，是本片的创作主张，不冒充这些论文的定理。

1. [G. J. Chaitin, Information-theoretic incompleteness (1992), IBM Research](https://research.ibm.com/publications/information-theoretic-incompleteness)：形式系统与可证明复杂度的限制。本文据此限定原稿对人类体验的外推，并用“打印有限串”的直接构造区分不可压缩与不可计算。
2. [K. Gödel, Über formal unentscheidbare Sätze… I (1931)](https://doi.org/10.1007/BF01700692)：原论文书目信息与入口；该出版页正文受访问限制。本轮没有据此声称通读付费全文。形式系统条件另参照[CMU《Mathematical Foundations for Computer Science》第7章课程资料](https://www.cs.cmu.edu/~cdm/resources/main-fund.pdf)及[4]中关于有效形式系统的讨论。
3. [C. E. Shannon, A Mathematical Theory of Communication (1948)，原文重印](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)：第6节关于离散熵及有限状态下的上界；不提供“灵魂熵”模型。
4. [A. M. Turing, Systems of Logic Based on Ordinals (1939)，论文及编者导言](https://people.math.ethz.ch/~halorenz/4students/Literatur/TuringOrdinalLogic.pdf)：原文第4节、印刷页173起关于oracle与o-machine；外来输入不等于消灭一切不可判定性。
5. [M. Kosinski, D. Stillwell & T. Graepel, Private traits and attributes are predictable from digital records of human behavior (2013), PNAS](https://doi.org/10.1073/pnas.1218772110)：从行为数据推断部分私密属性的研究；不能据此推断完美读心或所有私密记忆均可重建。
6. [Richard Fitzpatrick, Total Internal Reflection, University of Texas课程资料](https://farside.ph.utexas.edu/teaching/316/lectures/node129.html)：全反射的折射率方向与临界角条件。
