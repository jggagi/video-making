# 已选百炼的配音路径

这是本次实践提炼出的绑定示例。提供商选择、费用授权、CLI版本／技能版本预检、鉴权与错误处理以当前 `bailian-protocol` 为准；命令以当前 `bailian-gen` 的speech说明和 `bl speech synthesize --help` / `bl speech recognize --help` 为准。不要复制过时模型目录或把此处当成账号配置指南。

## Q 的视频旁白默认

Q 于 2026-10-23 明确选择：Q 的 video-making 当前及未来视频旁白默认使用百炼模型 `qwen-audio-3.0-tts-plus`、官方基础音色龙朗沫玥（完整音色 ID：`qwen-audio-3.0-tts-plus-longlangmoyue`）。当前任务明确指定的模型、音色和风格优先。这替代 2026-10-20 的 `longtian_v3` 默认；历史影片和案例仍保留原参数。语速 1.0 是本次试听起点，可按作品调整。默认风格沉稳、有分量、情绪克制，避免轻浮、过度轻快或广告腔；当前作品风格优先。沿用既有常规规模旁白 TTS 长期授权边界：可将当前影片已确定的旁白文本发送至百炼执行常规规模 TTS，无需逐片重复确认，但不扩展到额外 ASR、声音克隆、新提供商、显著增加的费用或账号发布。

## 合成

用户已选择百炼或适用上述默认授权时，先按当前 `bailian-protocol` 完成预检，并确认实际声音能力。Q 的视频旁白默认固定指定下列模型和完整音色 ID；其他未指定模型的百炼任务仍按当前 Profile 选择模型，并在返回清单中记录实际有效值。发现返回值与预检选择不一致时保留产物、停止相关调用，不能自动切换。

龙朗沫玥是官方基础音色，本次按官方基础音色 XLSX 第 553 行核验；不要假设 CLI 的 `--list-voices` 会列出该音色。视频旁白命令显式传入模型与完整音色 ID，避免当前 Profile 的模型默认值造成错配：

```sh
bl speech synthesize --text-file cue.txt --model qwen-audio-3.0-tts-plus --voice qwen-audio-3.0-tts-plus-longlangmoyue --rate 1.0 --format wav --sample-rate 24000 --out cue.wav --concurrent 1 --output json
```

以上示例仅列合成参数；实际执行须按当前 `bailian-protocol` 设置调用归因，无需修改全局 Profile。

不把命令的请求值当成已返回的模型／音色证据。解析需要的非敏感字段、验证真实音频和散列，其余原始响应不要输出到聊天或交付目录。逐段顺序生成适合这个小项目；并发和限流按当前提供商能力与本机负载决定。

## 自动回读

只有需要核对朗读内容且该音频属于已授权范围时，才提交人声轨。混入音乐、长静音或多说话人会影响结果。百炼CLI接受本地路径并上传，不需要另建公共文件服务器：

```sh
bl speech recognize --url voice-only.wav --language zh --output json
```

模型仍由已验证的Profile／当前CLI规则选择，不静默换成另一个模型。缓存本次音频散列和转写结果，避免重复收费。删除标点与空白可以辅助比较，但同音字、数字表达、漏读、儿化和句尾语气差异分别保留；需要听音才能决定是否改录。

## 《狂人日记》案例边界

本任务实际使用CosyVoice v3 Flash、`longsanshu_v3`、语速0.92、24kHz单声道原始WAV；23段共553字，15段新合成、8段经散列核对的旧缓存复制。清单区分一次网络失败在内的16次CLI尝试和15次成功合成。最终混音按影片需要转为48kHz双声道，4770帧／198.75秒；帧率24、静音两秒均为该片选择。

一次 `fun-asr` 回读给出13个字符编辑操作，涉及同音字、四千／4000、儿化与么／吗，没有把它们归一化为“完全一致”。字幕保持原文，人工试听未完成。这个例子说明缓存与自动检查可复用，而声音、分辨率、片尾长度和人工验收仍由具体任务决定。
