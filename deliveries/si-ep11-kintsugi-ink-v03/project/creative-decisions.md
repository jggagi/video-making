# v03 视觉与叙事决策

这一版回应观众对峡谷三维形体不成熟的反馈。完整保留v02的旁白、声音母带、字幕、时长和双手主体，把 [550,3600) 整个峡谷区间改成 Blender 离线渲染。旧版原地保留，可独立恢复。

核心决定是让碎片来自真实的母体轮廓。它必须离开、停住，再回到相同缺口，不能靠一块无对应孔位的悬浮瓷片暗示修复。两岸共享裂口，最终闭合，金色落在接缝。材质、相机和光照服务这个可看懂的动作。完整设计和迭代记录见 blender/ART-DIRECTION.md。

Remotion负责统一5400帧时钟、双手、字幕、转场、科学限定和PCM音轨。Blender源素材原生2160×3840，30fps；最终60fps合成显示每来源帧两次，未空间放大或补帧。引擎与采样配置通过实际测试确定，不把换用Blender本身当作质量证明。

原声轨复用，不新增云端生成或ASR。源脚本原字节保留；约37万亿、风险与科幻限定沿用用户已经选择的科学校订。0.5秒绝对静默和最后一句完整保留。

模型检查、自动媒体检查、人工听看与手机/App体验各自记录。此次继续制作不包含平台账号操作。
