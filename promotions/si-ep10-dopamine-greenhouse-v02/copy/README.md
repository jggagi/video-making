# EP10《多巴胺温室》v02 小红书文案与互动观察模板

## 发布文案

`title.txt` 是主标题，`body.txt` 是正文，`hashtags.txt` 是完整的十个标签，`pinned-comment.txt` 是置顶提问。`publication-content.json` 保存相同内容，便于核对和复用。主标题采用已定稿标题；另一个标题只作为备选。

正文将故事明确写成未来超级智能的科幻思想实验，第81秒的锁屏作为观看提示。末行创作说明界定虚构遥测和数值，不把它们说成当前手机或平台测量结果。

## 互动观察

`monitoring-template.csv` 只有表头，尚无发布或互动数据。每次观察追加一行并保留先前快照；`observation_utc` 使用 UTC 时间（ISO 8601）。只有在准确发布时间已知时才填写 `minutes_since_publication`，按该次观察时点计算。

数字 `0` 表示观察来源明确显示为零。空单元格表示未知、未显示或不可取得；不要把未知填成零。若指标不可见或来源有限，在 `limitations` 说明原因。`topical_themes` 只记观察到的评论主题，`source` 记下该快照来自哪里。

快照记录的是特定时点看到的数值，不能据此声称算法造成了浏览或互动变化，也不承诺算法加权、流量提升或十万以上播放。不要用估算值补齐不可见数据。
