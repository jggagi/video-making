# EP10 v2 数学画面模型

画面是未来SI思想实验，身体、神经节点、生物遥测与多巴胺数值均为创作隐喻，不是生理测量。v2没有训练IRL模型，也没有调用任何生成服务。原始剧本与音频时序保留。

| 画面 | 可编辑模型与动作 | 说明 |
| --- | --- | --- |
| 固定遥测 | Film.tsx：瞳孔+0.01..+0.42mm、延迟11.8..9.4ms按绝对帧变化；Menlo30逻辑px，838逻辑px框；字体就绪后断言每行scrollWidth不超clientWidth | 没有横向滚动，也不截字；原完整HUD常量保留在telemetry-lexicon.json作为原稿依据 |
| 虹膜中的谐波场 | EarlyActs.tsx：x/y分别叠加多个不同频率的正弦/余弦项，7层Lissajous干涉路径裁在r245虹膜内，以screen混合；瞳孔半径98..168逻辑px | 是参数曲线与视觉隐喻，不是多巴胺受体的形态或预测模型 |
| 形变膜与反馈 | 球面经纬投影，多频径向波、持续Y轴旋转、前后线段深度透明度；相机朝向轮廓先逆旋转避免侧面塌缩；碰撞后球面角半径随年龄增加的波环与曲线金粒子流 | 球面参数波用于表现弹性，不宣称求解了生物膜PDE或完整球谐特征模态 |
| 纵深茧体 | LateActs.tsx：8个Z层，每层16个茧体；针孔透视、前后平面淡出、相机偏航/俯仰与Z移动；近处大，远处小且透明 | 有限128个实例表达80亿孤岛的规模隐喻，不声称显式模拟80亿实例 |
| 神经点云与高维隔离 | 琥珀节点和经线构成示意人形；Clifford环面(x,y,z,w)=1/sqrt(2)·(cosu,sinu,cosv,sinv)，执行XW/YZ平面旋转，R4→R3→R2透视投影；左右方向相反 | 环面是实际R4参数投影；人形是示意点云，不是个人神经扫描。两侧投影域抽样半径≤148.35逻辑px，物理距离和认知光年是叙事尺度 |
| 断电与晶体 | Scenes.tsx：4854..4860先Y压缩再X收束，4860保留白线，4861..4890完全黑；Reality.tsx：9×5三维网格、52单位背面挤出、三角法线照明与透视偏转 | 30帧黑场完全遮掉文字、HUD和全部几何 |
| 粗糙碰撞 | 余烬连续退开并提前接近下一碰撞点；4900起每90帧一次撞击；18个碎火星按x=x0+vx/d·(1-exp(-dt))、y=y0+vy·t+g·t²/2运动，带琥珀/金/赤红轨迹 | 是有重力、横向阻尼的二维弹道模型，不声称完整接触力学模拟。声音母带不改变 |

说明文字只在5160..5399片尾出现，透明度0.35；主旁白字幕始终沿用v1的49逻辑px字号和1384..1492阅读区。最终AAC从v1复制，不重新编码；PCM母带哈希保持d787f5794a2f8cc76f159a58df02b66cd7721bb54e08d94149f1f0f251ecc968。

曲线原尺寸复核追加：谐波路径每层720采样点，采用统一0.8振幅界限避免硬截断折角；饱和旋涡每条1080采样点。静音视频中间轨保留在已核验的AgentDev，通过review/render-staging.json绑定路径、大小和SHA256，再复制原AAC到仓库内正式电影。
