# 有声 v2 · 半秒永恒

本版在原片的三分钟时间轴上加入百炼中文配音、原创电子氛围音乐和独立音效。原始无声 MP4、默认 Composition 和原版交付包保留。

## 文件与运行

- 有声成片：`out/the-half-second-eternity-voiced-v2.mp4`
- 八秒有声预览：`out/one-shot-preview-voiced-v2.mp4`，覆盖全片 156–164 秒。
- Remotion Composition：`HalfSecondEternityVoicedV2`。
- 完整混音母带：`public/audio-v2/soundtrack.wav`。
- 独立人声：`public/audio-v2/narration.wav`。
- 独立音乐：`public/audio-v2/ambient-score.wav`。
- 独立音效：`public/audio-v2/sound-design.wav`。
- 逐句文本与窗口：`audio-v2/voice-plan.json`。
- 百炼生成、原始文件、PCM 和容器规范化记录：`audio-v2/voice-manifest.json`。
- 实际混音参数、逐句位置、散列与响度结果：`public/audio-v2/mix-manifest.json`。

现有工程依赖不升级。安装项目依赖后，可以直接使用交付包里的音频重新渲染；播放、混音和渲染不调用云服务。

```sh
npm run typecheck
npm run check
npm run sample:voiced
npm run render:voiced
```

修改声音时，人声、音乐与音效分别保留，混音无需重新 TTS：

```sh
npm run voice:plan
npm run voice:sample
npm run voice:generate
npm run music
npm run mix
```

`voice:sample` 与 `voice:generate` 有缺失片段时会调用百炼；运行前须完成当前百炼技能的版本、鉴权和提供商预检。缓存匹配时按文本、模型、音色、参数与文件散列复用，只有未匹配片段需要重新处理。通过 `BAILIAN_CLI` 指定 CLI 路径，不将凭据放进工程。

音乐和混音脚本需要 Python 3 与 NumPy、FFmpeg、FFprobe。`SI_PYTHON=/absolute/path/to/python` 可指定环境；本机默认优先使用已安装的 Codex Python，再回退到 `python3`。独立机器如需再生成音乐，应在自己的隔离环境中安装 NumPy。交付的 WAV 无需依赖 Python 即可播放或由 Remotion 渲染。

## 配音

用户指定百炼，并明确同意先从 CLI 2.2.1 升至 2.3.0。已通过官方更新命令安装 2.3.0，并同步已安装的百炼技能；旧工程内的 2.2.1 工具副本保留，没有修改全局 PATH。

本片沿用当前 Profile 的默认 TTS 路由，不传 `--model` 覆盖。CLI 选定并报告 `cosyvoice-v3-flash`，音色为 `longtian_v3`（目录描述为“磁性理智男”），语速 0.96，原始输出为 24 kHz 单声道 PCM16。清单区分 CLI 报告值和供应商独立回显字段：后者未提供，保留为 `null`。

共有 22 个最终片段，另保留一个被替换片段。最初的短样本经参数与散列匹配复用于正式第二句。本次成功 TTS 请求共 23 次，包含最初样本与单句修订；没有更换模型或声音的兜底。实际账单和优惠额度未核对。公开价格参考：[阿里云模型信息](https://help.aliyun.com/zh/model-studio/cosyvoice-v3-flash)，不将字符估算当作实际收费。

字幕与发音文本分开保存。第一句将显示的 `300` 以“三百”送入 TTS。回读在“热失控、结构坍塌、能量发散——失败先发生在模拟之中”附近连续出现可疑多词；只将该句的发音标点改为明确的逗号与句号后重做。修订版回读为目标两句，没有该多词识别。字幕语义和其他片段不变。

原始流式 WAV 的 RIFF/data 头声明长度超过物理文件。规范化过程严格验证 PCM 格式、声道、采样率、byteRate、blockAlign 与 payload 对齐，仅修正容器长度；原件保存在 `public/audio-v2/raw/`，并记录原件散列、实际采样数及 PCM 散列。最终使用的 canonical WAV 均通过严格完整解码；没有靠忽略解码错误交付。

## 音乐与混音

音乐、玻璃泛音、数字转场、轻机械节拍与磁场冲击全部是本地程序化原创合成，使用固定种子 `421980160`；没有下载商业歌曲、使用第三方录音或生成歌词。

音乐以 D 小调及降 B、F、C 和声为底：前 30 秒疏朗低音铺垫；搜索段加入轻琶音；四维投影段提高谐波张力；比特与原子段以电子脉冲对照慢节拍；155–160 秒收低，在精确 160 秒加入晶体泛音和磁场低频，再柔和收束。

人声按实际非静音 RMS 做有限增益归一化，音乐在旁白期间降低 7 dB，提前 150 ms 开始避让，90 ms 渐入、450 ms 释放。音效独立保留。母带做两遍响度处理；由于原始动态范围 10.2 LU，FFmpeg 选择动态模式以满足目标范围，未强制进行不适用的线性增益。结果为 48 kHz、双声道 PCM16，精确 8,640,000 个采样帧 / 180 秒。

母带第二遍处理报告约 **−18.13 LUFS**、**−1.50 dBTP**，输出响度范围约 **6.7 LU**。这些是文件测量，不代表最终扬声器的主观听感。

## 验证与边界

- 全部 22 个 canonical 片段经散列核对与严格解码；声音没有越过分配窗口，没有片段重叠。
- 音乐、音效、人声和混音分别留存，母带完整解码为 180 秒。
- 有声八秒 Remotion 预览已实际渲染；其解码音频与母带 156–164 秒片段的零延迟相关系数为 **0.999950**，均为 384,000 个双声道采样帧，确认没有错截到音轨开头。
- 类型检查、原片几何和时间轴检查，以及有声版字幕区间检查通过。
- 百炼回读结果保存在 `audio-v2/asr-review.json`、`asr-focus-review.json` 与 `asr-voice06-r2.json`。全段及局部回读共发起四次请求；其中首个成功返回的纯文本因本地初版解析器假定 JSON 而未缓存，随后适配实际格式并保存文本。未保留签名下载链接或完整账户响应。
- 原始回读中的数字写法和“剪去/减去”“交点/焦点”等同音字差异保留；“扣紧”的局部回读与原文一致。没有把这些差异批量归一化后宣称逐字发音人工验收通过。

最终 MP4 的实际规格、完整音视频解码、编码后音频测量、视频抽帧与交付散列记录于 `out/voiced-v2-validation.json`。持续整片人工审听和用户最终播放设备的听感仍需试看确认。

最终视频轨为精确 10,800 帧 / 180 秒，AAC 为 48 kHz 双声道。编码后的容器呈现时长为 180.011 秒，解码 AAC 尾部含 512 个填充采样；原始 PCM 和画面时间轴保持 180 秒。编码后音频实测约 −18.16 LUFS、−1.45 dBTP，与完整混音母带在零延迟下的相关系数约 0.999944。全片音视频严格解码、fast start 与原无声版散列保留检查均通过；已查看编码后的结语字幕和最后一帧。
