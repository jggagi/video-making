# EP05 《兰道尔极限》

本项目制作120秒、60fps、7200帧的双画幅科学可视化短片。旁白、字幕、镜头和音效共用同一条时间轴；横屏目标为3840×2160，竖屏目标为2160×3840。原始输入保存在source/script.md，不做修改。

叙事从逻辑不可逆擦除的能耗下限进入算效与人脑参照，再转向行星级散热约束，最后讨论向更冷深空迁移的可能性。四幕各1800帧，片名卡、引句/片尾卡与下一集预告按独立子区间记录。

改编稿保留原来的十个旁白窗口和所有指定核心节点，并落实已批准的科学修订：1961年兰道尔提出的原则限定为300K下擦除未知比特；2.87仄焦耳是该条件下的理论下限；一万亿次擦除对应2.87纳焦耳；斯特藩—玻尔兹曼散热关系以给定温度和发射率为条件；行星级废热对生物圈写成风险而非必然结局；2.7K为背景温度，不是设备运行温度；费米悖论引句明确标作未经证实的假说。人脑约20瓦和约四十亿年作为修辞性近似保留。

每段分别保存原始台词、屏幕字幕和用于合成的读音文本。阿拉伯数字和单位在TTS轨中展开；引句前缀和EP.06标题只显示，不朗读。字幕每行最多14个汉字、每条最多两行，长句拆为多个连续字幕窗。

字幕现已绑定十段实际解码PCM的起止样本，并按短语权重估算句段内部边界；没有逐字对齐或ASR证据。两版SRT完全一致。S05首次13.60秒超窗，保留原录音后精简重复修饰，仅重录本段为12.96秒，未加速或截尾。

经本次用户明确授权，旁白使用阿里云百炼，CLI返回模型cosyvoice-v3-flash、音色longtian_v3、速率1.0。声音为同一份本地48kHz双声道PCM母带，每声道5,760,000样本；实测−16.9 LUFS、−1.8 dBTP。旁白、程序配乐、SFX与热噪声保留独立轨；所有事件frame×800映射到样本位置。热噪声轨在第5400帧前5ms淡出，从样本4,320,000起精确为零；乐音、旁白和低温锁定音可继续。

图像全部由本地解析公式、明确标注的示意粒子/谐振晶格和符号性片尾绘制，不调用生图、生视频或云端ASR。详见scientific-notes.md的逐条模型边界。竖屏保留安全区，HUD采用四行精简标签，完整遥测名保留在横屏及术语表。自动媒体验证、模型代表帧检查、连续人工听看和实际设备验收分别记录在review/acceptance.md。
